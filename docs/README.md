## 1. Общее описание проекта
Данный проект представляет собой библиотеку математических функций на языке **Python** для вычисления геометрических параметров базовых фигур: прямоугольника, круга, квадрата и треугольника. Библиотека позволяет рассчитывать площадь и периметр объектов на основе переданных линейных размеров сторон, радиусов или высот.
* **Состав проекта:**
  * `circle.py` — функции для расчета площади и периметра круга.
  * `rectangle.py` — функции для расчета площади и периметра прямоугольника.
  * `square.py` — функции для расчета площади и периметра квадрата.
  * `triangle.py` — функции для расчета площади и периметра треугольника.
* **Типы данных:** Все основные функции ориентированы на работу с целочисленными значениями (`int`) и со значениями с плавающей точкой (`float`) параметров.
* **Математическая база:** Проект использует встроенную библиотеку `math` для получения точного значения числа π.

## 2. Описание функций и примеры вызова

### Файл rectangle.py (Прямоугольник)

#### Функция `area(a, b)`
Возвращает площадь прямоугольника по двум его сторонам.
* **Параметры:**
  * `a` (`int` / `float`): длина первой стороны прямоугольника.
  * `b` (`int` / `float`): длина второй стороны прямоугольника.
* **Возвращаемое значение:**
  * `rectangle_area` (`int` / `float`): площадь прямоугольника (произведение сторон).

**Пример вызова:**
```python
import rectangle

print(rectangle.area(5, 3))  # Выведет: 15
```

#### Функция `perimeter(a, b)`
Возвращает периметр прямоугольника по двум его сторонам.
* **Параметры:**
  * `a` (`int` / `float`): длина первой стороны прямоугольника.
  * `b` (`int` / `float`): длина второй стороны прямоугольника.
* **Возвращаемое значение:**
  * `rectangle_perimeter` (`int` / `float`): периметр прямоугольника (удвоенная сумма сторон).

**Пример вызова:**
```python
import rectangle

print(rectangle.perimeter(5, 3))  # Выведет: 16
```

### Файл circle.py (Круг)

#### Функция `area(r)`
Возвращает площадь круга по заданному радиусу.
* **Параметры:**
  * `r` (`int` / `float`): радиус круга.
* **Возвращаемое значение:**
  * `circle_area` (`float`): площадь круга (π ⋅ r²).

**Пример вызова:**
```python
import circle

print(circle.area(3))  # Выведет примерно: 28.274333882308138
```

#### Функция `perimeter(r)`
Возвращает длину окружности (периметр круга) по заданному радиусу.
* **Параметры:**
  * `r` (`int` / `float`): радиус круга.
* **Возвращаемое значение:**
  * `circle_perimeter` (`float`): длина окружности (2 ⋅ π ⋅ r).

**Пример вызова:**
```python
import circle

print(circle.perimeter(3))  # Выведет примерно: 18.84955592153876
```

### Файл square.py (Квадрат)

#### Функция `area(a)`
Возвращает площадь квадрата по длине его стороны.
* **Параметры:**
  * `a` (`int` / `float`): длина стороны квадрата.
* **Возвращаемое значение:**
  * `square_area` (`int` / `float`): площадь квадрата (сторона в квадрате).

**Пример вызова:**
```python
import square

print(square.area(5))  # Выведет: 25
```

#### Функция `perimeter(a)`
Возвращает периметр квадрата по длине его стороны.
* **Параметры:**
  * `a` (`int` / `float`): длина стороны квадрата.
* **Возвращаемое значение:**
  * `square_perimeter` (`int` / `float`): периметр квадрата (сторона умноженная на 4).

**Пример вызова:**
```python
import square

print(square.perimeter(5))  # Выведет: 20
```

### Файл triangle.py (Треугольник)

#### Функция `area(a, h)`
Возвращает площадь треугольника по стороне и высоте.
* **Параметры:**
  * `a` (`int` / `float`): длина основания треугольника.
  * `h` (`int` / `float`): высота, опущенная на основание `a`.
* **Возвращаемое значение:**
  * `triangle_area` (`float`): площадь треугольника (половина произведения основания на высоту).

**Пример вызова:**
```python
import triangle

print(triangle.area(6, 4))  # Выведет: 12.0
```

#### Функция `perimeter(a, b, c)`
Возвращает периметр треугольника по трем его сторонам.
* **Параметры:**
  * `a` (`int` / `float`): длина первой стороны треугольника.
  * `b` (`int` / `float`): длина второй стороны треугольника.
  * `c` (`int` / `float`): длина третьей стороны треугольника.
* **Возвращаемое значение:**
  * `triangle_perimeter` (`int` / `float`): периметр треугольника (сумма всех трех сторон).

**Пример вызова:**
```python
import triangle

print(triangle.perimeter(3, 4, 5))  # Выведет: 12
```
